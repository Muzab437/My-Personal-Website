# Personal-Website

# 🌐 Personal Documentary Website

Website ini merupakan proyek web pribadi yang dikembangkan menggunakan **HTML, CSS, dan JavaScript**, dilengkapi dengan server backend sederhana berbasis **Node.js (`server.js`)**. Website ini menampilkan profil pribadi, aktivitas/portofolio, serta form interaktif.

---

### ⏱️ Waktu Pengerjaan
- **Durasi Pengerjaan:** ± 1–2 Minggu (Pengembangan bertahap mulai dari perancangan antarmuka, penambahan animasi CSS, logika interaktif JavaScript, hingga konfigurasi server).

---

### ✨ Fitur Utama
- **Tampilan Responsif & Modern:** Didesain dengan tata letak CSS yang bersih (`style.css`) serta animasi antarmuka yang halus (`animations.css`).
- **Skrip Interaktif:** Menggunakan JavaScript (`script.js`) untuk penanganan interaksi pengguna dan dinamika halaman.
- **Aset Kustom:** Dilengkapi dengan vektor kustom seperti avatar pribadi (`rayhan-avatar.svg`) dan identitas kampus (`telkom-logo.svg`).
- **Backend Ready:** Menyediakan file `server.js` untuk menjalankan website menggunakan lingkungan Node.js.

---

### 🛠️ Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js (`server.js`)
